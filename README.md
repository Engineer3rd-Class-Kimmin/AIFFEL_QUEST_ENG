
# AIFFEL_QUEST_ENG

[문제 해결·기여·AI 활용·평가와 한계](docs/APPLICATION_PORTFOLIO.md)를 추가했습니다. 신규 [Python 코드 평가](evaluation/portfolio-v1/RESULTS.md)는 **35건 중 31건 통과, 4건 실패**입니다. 원본 함수를 실제 실행한 개발 진단이며 전체 교육 과제의 모델 성능 점수는 아닙니다.


- AIFFEL 과정의 Python·데이터 분석·CV·NLP·LLM·배포 과제와 피어리뷰를 모았습니다.
- 수업 과제와 리뷰를 보존하며, 지원용 설명에서는 실제 코드와 평가 범위를 따로 확인할 수 있습니다.
